# Read Along

Прочитай `HANDOVER.md` целиком перед любой работой: там история проекта, устройство приложения, сборка, установка на iPhone, открытые задачи и правила работы с Владимиром.

Самое важное:
- Отвечай по-русски. Режим обсуждения по умолчанию: ничего не делай, пока Владимир не скажет «делай», «начинай» или «приступай». Когда всё ясно, спроси: «Все вопросы закрыты, начинать?»
- Перед техническим решением ищи в интернете, как это уже решили другие.
- Приложение — в `app/` (Expo SDK 58). Проверка: `npx tsc --noEmit` и `npx expo export --platform ios`. IPA собирается GitHub Actions при push в `app/**`.
- Рассказы и каталог (`stories.json`) лежат в корне и отдаются через GitHub Pages.
- ТЗ ведёт Натаха (Google Drive, папка «Наташа и Claude»), тексты рассказов не меняй.
